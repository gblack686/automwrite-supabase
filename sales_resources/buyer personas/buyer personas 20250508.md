# Buyer Personas Documentation

## Field Definitions

| Field | Description |
|-------|-------------|
| `persona_name` | Identifying name of the persona |
| `level` | Deal size/business complexity on a scale of 1-5 |
| `demographics` | Key identifying characteristics of the persona |
| `pain_points` | Challenges and problems the persona faces |
| `goals` | Primary business objectives and aspirations |
| `characteristics` | Personality traits and behavioral tendencies |

### Demographics Fields

| Field | Description |
|-------|-------------|
| `age` | Approximate age |
| `location` | Geographic location |
| `experience` | Years and type of professional experience |
| `firm_type` | Structure and size of business |

## Level Definitions

| Level | Description | Examples |
|-------|-------------|----------|
| **1** | Individual practitioners, sole proprietors | Independent Adviser Emma |
| **2** | Small family practices, limited resources | Cost-Conscious Chris |
| **3** | Growing firms, tech-forward mindset | Efficiency-Oriented Ethan, Growth-Oriented Olivia |
| **4** | Established mid-sized firms with multiple advisers | Scaling Firm Sam |
| **5** | Large enterprises, networks, high-worth focused | Wealth-Delegator William, Adviser Network Founder Alastair |

## Persona Selling Approach

### Independent Adviser Emma (Level 1)
- Focus on: Easy adoption, minimal disruption to practice
- Value proposition: More time for client interactions, staying competitive
- Addressing concerns: Simplicity, guided implementation, proven reliability

### Cost-Conscious Chris (Level 2)
- Focus on: Clear ROI, affordable pricing, visible time savings
- Value proposition: Do more with existing resources, reduce workload
- Addressing concerns: Fast implementation, immediate benefits, no hidden costs

### Efficiency-Oriented Ethan (Level 3)
- Focus on: Innovation, technological advantage, future-proofing
- Value proposition: Leadership through technology adoption, scalable solutions
- Addressing concerns: Demonstration of cutting-edge features, integration capabilities

### Growth-Oriented Olivia (Level 3)
- Focus on: Scalability, maintaining high-touch approach during growth
- Value proposition: Handling increased client load without sacrificing quality
- Addressing concerns: Proven success with rapidly growing firms

### Scaling Firm Sam (Level 4)
- Focus on: Team productivity, operational efficiency, work-life balance
- Value proposition: Solving bottlenecks, reducing paraplanner costs
- Addressing concerns: Implementation across teams, change management

### Wealth-Delegator William (Level 5)
- Focus on: Team empowerment, maintaining elite service standards
- Value proposition: Consistent quality, error reduction, reputation enhancement
- Addressing concerns: Minimal personal involvement required, team adoption

### Adviser Network Founder Alastair (Level 5)
- Focus on: Standardization across network, competitive advantage
- Value proposition: Enhancing network reputation, attracting top advisers
- Addressing concerns: Adoption across independent practices, maintaining autonomy
